
## Code from an earlier attempt

packages its venv had). You get its code only: not its notes, logs, measurements or conversation. Nothing in it is
guaranteed to work or to be right; it may be half-finished or built on wrong assumptions. Read it, reuse what holds
up, and verify everything against the robot yourself. The same rules apply to it as to your own code.
